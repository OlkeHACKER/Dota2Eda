# Dota2Eda 

Сайт заказа еды на Express, Prisma и PostgreSQL. Сервер одновременно отдаёт
веб-страницы и API, поэтому фронтенд обращается к базе через `/api`.

## Запуск

1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env`. Укажите рабочий `DATABASE_URL`
   PostgreSQL и длинный случайный `JWT_SECRET`.
3. Создайте таблицы в подключённой базе: `npm run db:migrate -- --name init`.
4. (Необязательно) Добавьте тестовые данные: `npm run seed`.
5. Запустите сайт: `npm run dev`.
6. Откройте `http://localhost:5000`. Не открывайте HTML напрямую через
   `file://`: тогда браузер не сможет обратиться к API.

### Запуск страниц через VS Code Live Server

Запустите backend командой `npm run dev`, затем откройте `index.html` или
`login.html` через Live Server (обычно адрес начинается с
`http://127.0.0.1:5500`). Frontend автоматически отправляет API-запросы на
`http://127.0.0.1:5000`; backend должен оставаться запущенным отдельно.

## Публикация в интернете через Render

В корне проекта есть `render.yaml` для бесплатного веб-сервиса. Чтобы создать
его, войдите в Render, выберите **New → Blueprint**, подключите репозиторий
`OlkeHACKER/Dota2Eda` и подтвердите создание сервиса `dota2eda`. Для уже
созданного Web Service укажите Start Command `npm run render:start`.

При настройке Render запросит `DATABASE_URL`: укажите строку подключения к
облачной PostgreSQL, предназначенной для этого проекта. Миграции Prisma
автоматически применятся при запуске сервиса. Используйте пустую базу данных
или сделайте резервную копию перед подключением существующей базы. `JWT_SECRET`
Render сгенерирует автоматически; секреты не добавляйте в GitHub.

После успешного деплоя Render покажет публичный адрес сайта. Проверить
подключение к базе можно по адресу `https://<адрес-сервиса>/api/health`.
Бесплатный веб-сервис может засыпать после простоя, а первый запрос после этого
будет медленнее.

## API

- `GET /api/health` — проверка соединения с базой данных.
- `GET /api/restaurants` — рестораны, блюда, винные рекомендации, история вечера и ингредиенты, если их добавил ресторан.
- `POST /api/auth/register` и `POST /api/auth/login` — регистрация и вход.
- `POST /api/orders` — оформить заказ (нужен Bearer-токен).
- `GET /api/orders/my` — история заказов вошедшего пользователя.
- `/api/admin/*` — защищённое управление собственным рестораном для роли `RESTAURANT_ADMIN`.
- `GET /api/restaurants/:id/tables` — доступность столиков.
- `POST /api/restaurants/:id/reservations` — бронирование столика (нужен Bearer-токен).
- `GET /api/restaurants/:id/qr.svg` — QR-код меню ресторана.

Владелец ресторана открывает панель по адресу `/admin.html`. Панель позволяет
редактировать ресторан и блюда, указывать видео интервью, переводы, винные пары,
происхождение ингредиентов, сезонность блюд, столики, таймлайн, бронирования и
заказы. Права на данные проверяются API по владельцу ресторана.

На сайте доступны RU/KK/EN для интерфейса; переводы меню задаются в панели.
3D-тарелка — интерактивная художественная визуализация, не скан настоящего блюда.
План зала и происхождение продуктов появляются после заполнения владельцем.
Фоновый звук запускается только после нажатия. Печать меню предлагает сохранить
страницу как PDF и включает QR-код для выбранного ресторана.

Карта происхождения использует тайлы OpenStreetMap (для просмотра карты
браузеру требуется интернет); поставщики и координаты не подставляются
автоматически — их добавляет администратор ресторана.

## Импорт меню

Все 15 ресторанов и 300 блюд из предоставленного меню находятся в
`prisma/menu-data.json`. Импорт в текущую базу: `npm run menu:import`.
Команду можно запускать повторно: записи импорта обновляются или пропускаются
без создания дубликатов.

Цены показываются и в исходных долларах, и в тенге. Тенговые цены рассчитаны
по официальному курсу Нацбанка Казахстана на 5 октября 2026 года
(1 USD = 447,73 KZT). Этот курс записан для меню и не обновляется автоматически.

Проверьте `DATABASE_URL` и доступность сервера PostgreSQL, если проверка
`/api/health` завершается ошибкой. Не публикуйте значения из `.env`.
